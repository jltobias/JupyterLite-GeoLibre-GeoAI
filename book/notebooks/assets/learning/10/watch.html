Browser machine learning: graph features feed K-Means and Isolation Forest.

Transcript and code landmarks

  1. 00–08s · Connect

    Represent partnerships as graph edges with distance weights.

    G.add_edge(..., km=...)
  2. 08–16s · Measure

    Summarize each node's degree, bridging role and connection distances.

    nx.betweenness_centrality(...)
  3. 16–24s · Learn

    Group similar graph profiles and identify unusual combinations.

    KMeans(n_clusters=4)
  4. 24–32s · Map

    Return scores to cities with known coordinates, keeping missing records visible in the table.

    point_collection(mapped)
